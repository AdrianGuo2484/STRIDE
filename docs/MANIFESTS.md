# Private manifest contracts

The CSV files described below are private runtime inputs and must not be
uploaded. Identifiers must be de-identified. Image paths can be absolute or
relative to the CSV location.

## BraTS2024 segmentation

`data/brats2024_segmentation.csv` requires:

```text
patient_id,case_id,t1ce_path,t1_path,t2_path,flair_path,abnormal_mask_path
```

`patient_id` controls five-fold grouping. `abnormal_mask_path` is a binary or
multilabel NIfTI mask; every nonzero label is treated as abnormal tissue.

`data/burdenko_visits.csv`, used only for frozen PSN inference, requires:

```text
case_id,t1ce_path,t1_path,t2_path,flair_path
```

`t1ce_path` and `flair_path` must be present. `t1_path` and `t2_path` may be
empty; prior inference inserts zero-valued channels for either optional
modality.

## LUMIERE longitudinal pretraining

`data/lumiere_pairs.csv` requires:

```text
pair_id,patient_id,split,delta_weeks,next_rano_id
t_ct1_path,t_t1_path,t_t2_path,t_flair_path
next_ct1_path,next_t1_path,next_t2_path,next_flair_path
t_deep_seg_path,next_deep_seg_path
```

The loader prefers optional skull-stripped columns ending in `_ss_path` and
falls back to the corresponding paths above. It also falls back from
`<prefix>_deep_seg_path` to `<prefix>_hdglio_seg_path`.

`split` must be `train` or `val`. Follow-up RANO IDs are:

```text
PD=0, SD=1, PR=2, CR=3, PRE_OP=4, POST_OP=5, UNKNOWN=6
```

Reference masks are supplied directly to SoftGate. They are not segmentation
targets of the longitudinal model.

## Burdenko fine-tuning

`data/burdenko_pairs.csv` requires:

```text
pair_id,patient_id,delta_weeks,clinical_label
t_t1ce_path,t_t1_path,t_t2_path,t_flair_path
next_t1ce_path,next_t1_path,next_t2_path,next_flair_path
t_path_prob_pred_brats2024,next_path_prob_pred_brats2024
```

`clinical_label` accepts either class names or integer IDs:

```text
SD=0, PsP=1, TP=2
```

Only adjacent eligible visits should be paired. Each pair inherits the
patient's curated final label. T1CE and FLAIR are required at both visits; T1
and T2 may be empty. The loader inserts zero channels for optional missing
modalities and supplies modality-presence indicators.

Lesion priors may be 3D `.npz` probability arrays or NIfTI hard masks. Files
generated by `predict_lesion_priors.py` contain an explicit
`abnormal_probability` array. For compatibility with multi-channel probability
files, `probability_mode: foreground_max` computes a continuous union using the
voxel-wise maximum.

The longitudinal configurations use the same semantic channel order in both
datasets: `T1CE/cT1, T1, T2, FLAIR`. Training validates this order against the
LUMIERE checkpoint before transferring any parameters.
